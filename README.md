# Myntra Landing Page

This project is a static e-commerce landing page inspired by Myntra. It features a stylish navigation bar, category sections, product cards, and a clean layout built using HTML and CSS.


## Features
- Simple and modern UI
- Navigation bar with dropdown-style sections
- Product showcase cards
- Responsive layout for browser viewing

## How to Run
1. Open the project folder in your browser.
2. Launch [index.html](index.html) to view the webpage.

## Technologies used

- HTML
- CSS
- Font Awesome icons
